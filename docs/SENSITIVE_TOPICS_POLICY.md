**最后更新日期**: 2025年1月27日

## 📋 概述

WTS灵签APP（以下简称"本应用"）致力于提供积极、健康的娱乐体验。为了维护网络和谐、避免争议，并确保合规运营，本应用对涉及宗教、种族、主权争议、极端主义及反社会问题的查询一律不予回答。

## 🛡️ 处理机制

### 1. 自动检测
- 系统会在用户提问时自动分析问题内容
- 使用关键词匹配和语义分析相结合的方法
- 优先级：敏感话题检查 > AI分析 > 法律风险检查

### 2. 拒绝流程
```
用户提问 → 敏感话题检测 → 发现敏感内容 → 生成拒绝回复 → 返回用户
```

### 3. 拒绝回复生成
- 根据触发的主要敏感类别生成相应拒绝回复
- 如果涉及多个类别，按最高敏感度优先
- 拒绝回复采用温和、尊重的方式
- 提供替代建议和指导

### 4. 日志记录
- 记录敏感话题查询（不记录具体内容）
- 统计敏感话题访问频率
- 用于改进和优化系统
- 保护用户隐私
