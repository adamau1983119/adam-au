APP UI示意圖 — 擲杯

目的：引導完成三次擲杯並顯示結果，判斷是否可進入籤文內容頁。

```
+--------------------------------------------------+
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                     擲杯                          |
|  說明：請擲杯三次，每次擲杯後，待杯靜止，再按按鈕。  |
|                                                  |
|  次數： [ 1 / 3 ]                                 |
|  本次結果： [ 正／反 ]（由後端返回）               |
|  累計結果： [ 正x? 反x? ]                         |
|                                                  |
|                 [ 擲杯 / 下一次 ]                 |
|                                                  |
|  完成條件：至少有兩個正反結果（由後端判定）        |
|                                                  |
|  [ 重新抽籤 ]                 [ 完成並查看籤文 ]    |
+--------------------------------------------------+
```

主要元素：
- 流程說明與次數進度（對應需求文件第13條）
- 結果顯示與完成條件（對應需求文件第15條）
- 動作：重新抽籤（回抽籤流程）、完成並查看籤文（進入籤文內容頁）
