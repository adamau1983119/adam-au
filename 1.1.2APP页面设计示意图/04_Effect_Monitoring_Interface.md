## 🎨 設計規範

### 數據視覺化
- **折線圖**：深藍色線條，圓點標記
- **長條圖**：漸變藍色填充
- **圓餅圖**：多色彩搭配
- **趨勢箭頭**：綠色上升，紅色下降

### 狀態指示器
- **✅ 達標**：綠色圓點 + 文字
- **⚠️ 警告**：橙色圓點 + 文字
- **❌ 未達標**：紅色圓點 + 文字
- **📊 正常**：藍色圓點 + 文字

### 卡片設計
- **數據卡片**：白色背景，陰影效果
- **警報卡片**：淺橙色背景
- **成就卡片**：淺金色背景
- **趨勢卡片**：淺藍色背景

### 圖表設計
- **折線圖**：平滑曲線，數據點標記
- **長條圖**：圓角設計，漸變填充
- **圓餅圖**：3D 效果，標籤顯示
- **熱力圖**：顏色深淺表示數值大小

## 📱 功能說明

### 主要功能
1. **轉換率監控**：實時追蹤轉換率變化
2. **評分分析**：用戶評分和評論分析
3. **下載量追蹤**：下載量趨勢和來源分析
4. **目標管理**：設定和追蹤績效目標
5. **警報系統**：異常情況即時通知

### 數據來源
- Google Play Console API
- Play Integrity API
- 用戶評論數據
- 競品分析數據

### 監控指標
- **轉換率**：下載轉換率變化
- **評分**：用戶評分趨勢
- **下載量**：下載量增長趨勢
- **留存率**：用戶留存率變化
- **排名**：App Store 排名變化

### 警報設定
- **下載量異常**：下降超過 10%
- **評分異常**：下降超過 0.2⭐
- **轉換率異常**：下降超過 5%
- **排名異常**：下降超過 5 位
