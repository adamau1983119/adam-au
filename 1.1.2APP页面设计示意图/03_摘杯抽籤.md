APP UI示意圖 — 摘杯抽籤

目的：以擲杯驗證籤意的抽籤流程（強制擲杯）。

```
+--------------------------------------------------+
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                   摘杯抽籤                         |
|  流程：選擇占卜類別 → 求籤步驟 → 抽中簽預覽 → 擲杯(必做) |
|                                                  |
|  [ 選擇占卜類別 ]  （事業/財運/自身/家庭/婚姻/遷徙/名譽/健康/友誼/其他）
|                                                  |
|  提示：本流程需完成三次擲杯以確認籤意               |
|                                                  |
|                                      [ 返回首頁 ] |
+--------------------------------------------------+
```

主要元素：
- 入口：選擇占卜類別（前往類別選擇頁）
- 提示：需完成三次擲杯
