APP UI示意圖 — 每日一籤

目的：每天限一次的簽文抽取，可選擇所求事項。

```
+--------------------------------------------------+
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                   每日一籤                         |
|  流程：選擇占卜類別 → 求籤步驟 → 抽中簽預覽 → 擲杯(可選) |
|                                                  |
|  [ 選擇占卜類別 ]  （事業/財運/自身/家庭/婚姻/遷徙/名譽/健康/友誼/其他）
|                                                  |
|  [ 抽今日之籤 ]（若今日已抽，顯示：今日已抽，請明日再來）   |
|                                                  |
|                                      [ 返回首頁 ] |
+--------------------------------------------------+
```

主要元素：
- 入口：選擇占卜類別（前往類別選擇頁）
- 主按鈕：抽今日之籤（與後端校驗是否已抽）
