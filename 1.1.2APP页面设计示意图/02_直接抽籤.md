APP UI示意圖 — 直接抽籤

目的：快速抽籤，並可依所求事項分類。

```
+--------------------------------------------------+
|                   直接抽籤                         |
|  流程：選擇占卜類別 → 求籤步驟 → 抽中簽預覽 → 擲杯 |
|                                                  |
|  [ 選擇占卜類別 ]  （事業/財運/自身/家庭/婚姻/遷徙/名譽/健康/友誼/其他）
|                                                  |
|                                      [ 返回首頁 ] |
+--------------------------------------------------+
```

主要元素：
- 入口：選擇占卜類別（前往類別選擇頁）
- 流程提示：顯示後續步驟（求籤步驟 → 抽中簽 → 擲杯）
