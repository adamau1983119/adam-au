APP UI示意圖 — 籤文內容

目的：顯示對應的籤文全文，並提供與 DeepSeek 的對話入口。

```
+--------------------------------------------------+
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                   第 XX 籤  標題（可選）            |
|  內容：                                           |
|   （由後端隨機輸出 1~100 之一）                    |
|   .............................................  |
|   .............................................  |
|                                                  |
|  問答（DeepSeek）：                                |
|   [ 在此輸入問題（200字內）................. ]     |
|   [ 發送 ]  →  進入「對話界面」                     |
|                                                  |
|  [ 返回 ]                             [ 回首頁 ]  |
+--------------------------------------------------+
```

主要元素：
- 內容：顯示抽中籤文全文（對應需求文件第10、11、16條）
- 對話框：輸入問題並發送，前往對話界面
