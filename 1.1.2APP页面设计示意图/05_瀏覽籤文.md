APP UI示意圖 — 瀏覽籤文

目的：瀏覽1~100號所有籤文（非抽籤）。

```
+--------------------------------------------------+
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                   瀏覽籤文                         |
|  篩選： [ 事業 ] [ 財運 ] [ 自身 ] [ 家庭 ] [ 婚姻 ] ... |
|                                                  |
|  清單（1~100）：                                   |
|   #1  第一籤（略） → [ 查看 ]                      |
|   #2  第二籤（略） → [ 查看 ]                      |
|   ...                                            |
|                                                  |
|                                      [ 返回首頁 ] |
+--------------------------------------------------+
```

主要元素：
- 清單：1~100籤索引與查看入口
- 篩選：依所求之事過濾（可選）
