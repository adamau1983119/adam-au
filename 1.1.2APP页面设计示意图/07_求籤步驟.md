APP UI示意圖 — 求籤步驟

目的：引導使用者按傳統流程完成求籤儀式並開始抽籤。

```
+--------------------------------------------------+
|                   求籤步驟                         |
|  1. 雙手合十，默念「黃大仙有求必應」3次            |
|  2. 默念姓名、出生地與時間、年齡與所求之事          |
|  3. 嗯。點擊下方按鈕開始抽籤                        |
|                                                  |
|                      [ 開始抽籤 ]                 |
|                                                  |
|  [ 上一步 ]                             [ 返回 ]  |
+--------------------------------------------------+
```

主要元素：
- 步驟文字（對應需求文件第9條）
- 主要按鈕：開始抽籤（進入抽中簽預覽）
- 導覽：上一步（回類別選擇）、返回（回首頁）
