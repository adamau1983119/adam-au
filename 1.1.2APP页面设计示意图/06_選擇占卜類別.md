APP UI示意圖 — 選擇占卜類別（適用：直接抽籤／摘杯抽籤／每日一籤）

目的：在抽籤前選擇所求事項類別。

```
+--------------------------------------------------+
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                 選擇占卜類別                       |
|  請選擇所求之事：                                 |
|                                                  |
|  [ 事業 ]  [ 財運 ]  [ 自身 ]  [ 家庭 ]  [ 婚姻 ]  |
|  [ 遷徙 ]  [ 名譽 ]  [ 健康 ]  [ 友誼 ]  [ 其他 ]  |
|                                                  |
|  [ 返回 ]                             [ 下一步 ]  |
+--------------------------------------------------+
```

主要元素：
- 類別按鈕：事業、財運、自身、家庭、婚姻、遷徙、名譽、健康、友誼、其他
- 導覽：返回（回前一頁）、下一步（進入求籤步驟）
