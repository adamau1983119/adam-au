APP UI示意圖 — 擲杯結果

目的：展示三次擲杯後的最終判定，決定是否進入籤文內容或返回抽籤。

```
+--------------------------------------------------+
|                    擲杯結果                         |
|  三次擲杯紀錄：                                     |
|   第一次： 正／反                                   |
|   第二次： 正／反                                   |
|   第三次： 正／反                                   |
|                                                  |
|  系統判定：                                        |
|   - 若至少有兩個正反結果：可視為生效               |
|   - 否則：未生效，請重新抽籤                       |
|                                                  |
|  [ 重新抽籤 ]                      [ 查看籤文內容 ] |
+--------------------------------------------------+
```

主要元素：
- 紀錄：列出三次擲杯結果
- 判定：是否達成「至少兩個正反結果」條件（對應需求文件第15條）
- 動作：重新抽籤（回抽籤流程）、查看籤文內容（進入籤文內容頁）
