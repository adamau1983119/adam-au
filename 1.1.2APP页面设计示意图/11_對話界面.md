APP UI示意圖 — 對話界面（DeepSeek）

目的：基於抽中之籤文與使用者問題，提供 200 字內的答覆。

```
+--------------------------------------------------+
|                    對話界面                         |
|  對話紀錄：                                       |
|   [我] 問題內容.................................   |
|   [DeepSeek] 回答（限 200 字內）................   |
|   [我] ........................................   |
|   [DeepSeek] ..................................   |
|                                                  |
|  輸入： [ 在此輸入訊息................. ] [ 發送 ]  |
|                                                  |
|  註：簽文會自動附帶給 DeepSeek 作為上下文           |
|                                                  |
|  [ 返回籤文 ]                        [ 回首頁 ]     |
+--------------------------------------------------+
```

主要元素：
- 對話氣泡清單：時間排序
- 輸入框 + 發送
- 返回：返回籤文內容頁或回首頁
