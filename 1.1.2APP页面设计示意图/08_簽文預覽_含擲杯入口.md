APP UI示意圖 — 簽文預覽（含擲杯入口）

目的：顯示抽中的第幾籤，並提供擲杯入口以驗證籤意。

```
+--------------------------------------------------+
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                                                  |
|                 你已抽中 第 XX 籤                  |
|  簽文摘要：.....................................  |
|  （完整內容稍後在籤文內容頁顯示）                 |
|                                                  |
|  擲杯驗證（需完成三次）：                          |
|   [ 擲杯 1 ]   [ 擲杯 2 ]   [ 擲杯 3 ]             |
|                                                  |
|  其他： [ 直接查看籤文 ]（可跳過擲杯）             |
|                                                  |
|  [ 返回 ]                             [ 下一步 ]  |
+--------------------------------------------------+
```

主要元素：
- 標題：你已抽中第幾籤（對應需求文件第12條）
- 擲杯按鈕：三個入口（對應需求文件第12條）→ 進入擲杯頁
- 其他入口：直接查看籤文（可選）→ 進入籤文內容頁
